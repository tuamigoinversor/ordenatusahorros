CÓMO PUBLICAR UN ARTÍCULO NUEVO
  1. En GitHub, entra en la carpeta articulos/, copia _plantilla.md con un nombre como 2026-11-03-titulo-del-articulo.md y edítala (título, fecha, categoría, resumen, imagen y texto).
  2. Pulsa "Commit". En 1-2 minutos GitHub regenera la web: página del artículo, listado del blog, los 3 últimos de la home y el RSS.
  3. Para programar un artículo, pon una fecha futura: se publica solo ese día (la web se reconstruye cada mañana).
  4. Para guardar un borrador sin publicar, déjalo en articulos/borradores/.
  Los enlaces dentro de un artículo se escriben así: [texto](/inversion-tactica-geda/) o [texto](/aprende/otro-articulo/).
  Una vez, en GitHub: Settings > Pages > Source: "GitHub Actions". El flujo está en .github/workflows/publicar.yml.
  Si prefieres no usar GitHub Actions: instala Python, ejecuta "pip install markdown pyyaml" y "python tools/build_blog.py", y sube el resultado.
  Esto no está probado en GitHub: el script sí se ha probado aquí; el flujo de GitHub Actions, no.

CÓMO SUBIRLO A IONOS
  1. Crea el subdominio (por ejemplo nueva.tuamigoinversor.com) con una carpeta propia. No uses la de WordPress.
  2. Sube el CONTENIDO de esta carpeta respetando la estructura (index.html en la raíz del subdominio).
  3. Activa el certificado SSL del subdominio.
  4. Comprueba: home, test emergente, "Comparar" y "Simular" en una tarjeta, GEDA y su menú, modo claro/oscuro.
  Si lo abres haciendo doble clic en index.html desde el disco, todo funciona salvo que algunos navegadores
  no cargan bien la foto/fuentes locales; para probar, mejor usa el subdominio.
